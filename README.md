# GateShield

Link / scam protection — scan any URL or message before you click it.
A [knuckls.com](https://knuckls.com) project.

## What it does
- Paste a link or suspicious message → get a verdict in plain English: **safe / caution / danger**
- Google Safe Browsing API check (known phishing/malware)
- Lookalike domain detection (paypa1.com, amaz0n.net, etc.)
- Domain age via WHOIS — scam sites are almost always days old
- Community blocklists (PhishTank, URLhaus)
- Message heuristics — "prize you never entered", "order you never placed", urgency + gift-card language

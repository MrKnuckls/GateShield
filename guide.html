Getting started

Paste any link, or a whole suspicious text message / email snippet, into the box and hit SCAN ▸ (or Ctrl+Enter). You get a verdict in plain English with the reason for every flag. Nothing you paste is sent anywhere — the checks run entirely inside your browser.

The three verdicts

VerdictMeaning
SAFENo scam signals found. Still not a guarantee — heuristics can't see intent.
CAUTIONSeveral signals. Don't use the link; open the company's real site or app yourself instead.
DANGERMultiple strong scam signals. Do not click, do not reply, delete it.

What it checks

In URLs: bare IP-address servers, punycode (lookalike-alphabet domains), imitations of 26 well-known brands (paypal, amazon, your bank, USPS, Steam…), real brand names buried in the path of a different domain, high-abuse domain endings (.top, .xyz, .zip…), link shorteners that hide the destination, direct .exe/.apk downloads, the @ URL trick, "secure / verify / login" words in a domain name, unencrypted http, and structural oddities like hyphen-stuffed or over-deep subdomains.

In messages: the classic hooks — "your account is suspended", a prize you never entered, delivery-fee texts, requests for passwords / OTP codes / card numbers, payment-pressure via Zelle / crypto / wire, artificial urgency ("within 24 hours"), shouting in caps, and it runs every link inside the message through the URL checks.

What it can't catch

GateShield is pattern recognition, not an oracle. It can't check a live blocklist, look up the domain's age, or verify a certificate — those need server-side lookups and are planned. A brand-new scam site with a squeaky-clean domain and no brand imitation can still pass. The rule stands: if a message pushes you toward a link with urgency, go to the company's real site yourself instead of clicking.

Install as an app

Android (Chrome): open the site → tap ⋮ menu → Add to Home screen → Install. It launches full-screen like a native app.

PC (Chrome/Edge): click the install icon in the address bar, or ⋮ → Cast, save and share → Install page as app.
